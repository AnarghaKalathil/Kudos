# 🎯 Kudos Frontend (React + Vite)

This is the **React + Vite** frontend for the Kudos application — a peer recognition and feedback platform.

---

## ⚙️ Tech Stack

- ⚛️ React
- ⚡ Vite
- 🎨 Material UI (MUI)
- 🎯 React Router v6
- 💅 SCSS Modules

## 🚀 Getting Started

### 1. **Navigate to the frontend directory**

```bash
cd app-frontend

2. Install dependencies

npm install

3. 🔥 Start the development server

npm run dev
